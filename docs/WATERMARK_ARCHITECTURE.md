# 水印对象与安全移除设计

## 设计目标

PDF Studio Lite 添加的文字和图片水印共用同一套对象管理机制。水印必须可识别、可枚举、可单独移除，并且不能依赖文字内容、颜色或重复次数猜测身份。

## 对象标识

每次应用水印都会生成一个 UUID。每个水印绘制实例使用独立 PDF 内容流，流首部写入合法 PDF 注释：

`%PDFStudioLite-Watermark:<base64url-json>`

JSON 包含模式版本、UUID、标签、类型、创建时间、页码、实例序号和参数快照。保存后重新打开文件并扫描全部页面内容流，只有标识和数量验证通过才替换目标输出。

## 删除策略

删除时只从页面 `/Contents` 数组中移除 UUID 匹配的独立内容流引用。正文流、文字对象、矢量对象、普通图片和普通注释均不参与匹配，也不会被重写。随后另存为新 PDF，并再次扫描确认目标 UUID 已不存在。

未引用的图片资源可能暂时保留在页面资源字典中，但不会显示或影响正文；安全性优先于激进清理共享资源。输出保存时启用 PDF 垃圾对象回收。

## 兼容性边界

- 自有标识水印：支持安全移除。
- 明确的独立 Watermark Annotation：检测 `/Subtype /Watermark`，允许按注释对象删除。
- 重复文字或图片对象：按跨页重复和相近位置给出疑似结果，但删除按钮禁用。
- 扫描件像素中的水印：不属于对象级水印，稳定版不执行自动修复。
- 数字签名：任何另存编辑都会使原签名失效，界面必须提示。
